## How to Use:
1. Clone this repository to your own device
2. If you're using Laragon, put the project folder in /laragon/www, but if you're using XAMPP, put the project folder in /htdocs
3. Run the index.html, and you will get directed to the (fake) login page.
4. On the (fake) login page, you can insert any username and password. 
5. Right after you click login, you'll get directed to the original Instagram login page.
